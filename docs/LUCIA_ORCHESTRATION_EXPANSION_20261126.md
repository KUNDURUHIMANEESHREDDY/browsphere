# Lucia orchestrator expansion — 26 November 2026

This change extends native evidence contracts and adds fail-closed local report export. It does **not** establish general autonomous browsing, form execution, or calendar/MCP write reliability.

## Explicit factual dimensions

Read-only source research can compile `price`, `duration`, and `opening_hours` as separate factual obligations when the user's objective requests them. Each needs an observed, relevant value, not merely a visit to a page. Focused DOM capture uses goal-derived terms. Existing source identity, quote validation, conflict blocking for free-team capacities, and independent source verification remain authoritative.

## Semantic planning reliability

Model-produced semantic labels are advisory. A fabricated label can be removed if no explicit ordered goal is present; fabricated negative constraints still cause model plan rejection. When an ungrounded semantic interpretation prevents the model draft from being validated, Lucia can select a deterministic native minimum plan with the original goal and existing browser action permissions. Explicit ordered clauses remain protected. On-page form goals omit an unnecessary navigation stage; the Form specialist must still independently confirm successful submission.

## Local verified report artifact

When a user explicitly requests a research report with source citations, *and not an online editor, private account, or publication*, the native final-verification gate can produce a local Markdown file. It requires `evidence_checked`, exact quotes matching at least two distinct observed HTTPS sources, and a successful SHA-256 disk readback. File creation failures cannot produce a successful completion receipt. `agent:document_artifact` includes artifact metadata, not raw page text.

## Safety constraints

All browser and MCP actions retain native policy checks. The original user goal, form submission approvals, private browsing isolation, and final independent verification cannot be overridden by this local report export or advisory planner fallback. No installed production executable or main branch was changed by this experimental feature branch.
