# Adaptive catalog recovery

The run tracks distinct browser-action and observation budgets for each named retailer (22 proposals and 60 observations). The outer loop remains bounded and cancellation remains active. Pending query, filter and pagination actions are closed by fresh observations, not execution acknowledgements. Result link changes extend settling at most three times per result interaction. Next-page buttons are eligible only on a submitted public results page, with a two-page cap; confirmation requires changed product links and preserved query/filter scope.

If the retailer search and category paths fail, the engine may construct a public Google search from the compiled product identity and the exact named retailer domain. Only rendered direct HTTPS product URLs without query parameters, credentials or fragments can be selected; ordinary policy/allowlist and objective validation still apply. No consent, sign-in, CAPTCHA, or access restrictions are bypassed. Google snippets are never price evidence.

An incomplete run emits a distinct partial_evidence report containing only separately source-verified products, listing unverified retailers explicitly. The strict benchmark still requires both retailer product pages and prices; partial evidence is not a pass.
