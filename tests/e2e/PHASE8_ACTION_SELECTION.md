# Phase 8 consolidation

The earlier isolated Phase 8 catalog ranker was superseded by the newer catalog_research and strategy_ledger modules. It remains in the local prototype worktree rather than running a competing action planner. Main now incorporates its independent documentation version affinity guard and its regression test. The guard prevents navigating to a different observed release from the current branch; it does not establish that an arbitrary page is current or verify its factual content. The SQL hierarchy recognizer accepts numbered headings with optional "The".

The current catalog implementation retains retailer-specific public discovery, grounded candidate ranking, asynchronous confirmation, and partial evidence reporting. Passing unit tests does not establish live retailer or documentation benchmark completion.
