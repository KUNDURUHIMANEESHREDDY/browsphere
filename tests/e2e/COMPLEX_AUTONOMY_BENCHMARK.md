# Complex Lucia autonomy release gate

Run on an isolated native WebView2 profile with real local models. No login, purchases, reservations, payments, downloads or other external writes. Never bypass a site access restriction. Report blocked separately from passed.

- Cross-site technical research: Python data structures and MDN Array.map. Require both source URLs, actual quoted findings and distinct requested properties.
- Dependency DAG: no-match MCP discovery, real GitHub repository API, referenced package name into real PyPI API, scalar comparison, native browser handoff. Require receipts and actual destination.
- Negative DAG: deliberately wrong expected scalar must prevent downstream PyPI dispatch and browser navigation. Require failed/blocked graph state.
- Future gates: multi-field public journey search (search only); comparison of three independently observed products or libraries; multi-page documentation navigation with evidence synthesis; dynamic result filtering; bounded recovery after delayed or unavailable public page.

The public APIs are reached via test-owned read-only MCP adapters, not vendor-hosted MCP servers. Expected values are independently checked. The explicit graph is an orchestration test, not evidence of natural-language graph generation.

Set LUCIA_COMPLEX_TEST=1 and optionally LUCIA_COMPLEX_CASE=research, graph, or negative. Run run-lucia-cross-site-live.ps1 -OnlyWikipedia against a current executable and distinct CDP port. No production profile changes.
